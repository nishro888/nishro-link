# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussions about the work. Harassment, insults and personal attacks are not
tolerated in issues, discussions, pull requests or anywhere else in the
project.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/nishro888). Reports are handled confidentially,
and the maintainer may remove, edit or reject contributions, and temporarily
or permanently ban participants, as the Covenant describes.
